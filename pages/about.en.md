# About Awesome Rust AI Libraries

Awesome Rust AI Libraries is a curated, continuously updated directory of Rust crates, frameworks and tools for building AI systems — with a focus on open-source projects that have real documentation, examples and an active community.

## What you'll find here

- **Training and inference** — tensor libraries and runtimes such as candle, burn, dfdx and tract.
- **LLM and agent tooling** — API clients, prompt and orchestration frameworks, agentic systems.
- **Language and data** — NLP, text processing, data formats, stream processing and optimization.
- **Generative AI and code generation** — crates for images, audio and code.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new crates, keep existing listings current and organize everything into categories and tags; every listing links back to its repository or crates.io page.

Maintaining a Rust AI crate that isn't listed? Use the **Submit** page to add it.
